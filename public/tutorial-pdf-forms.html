PDF Forms Tutorial (MCP)

Extract fields, fill values, and flatten forms to produce a signed-ready PDF.

When this tutorial helps
  • Onboarding flows: users upload a PDF form and you auto-fill with profile data.
  • Back office: extract field names for mapping to CRM / ERP objects.
  • Compliance: generate a flattened PDF so recipients can’t edit fields after submission.

1) Upload your PDF

Most pipelines begin with a file URL, a user upload, or a document pulled from storage.

{
  "file": "w2_template.pdf"
}

2) Extract form fields

Use the PDF forms tool to list fields (names, types, and current values). This step is critical because PDF field names are often non-obvious (e.g., topmostSubform[0].Page1[0].f1_01[0]).

// MCP tool call (conceptual)
{
  "tool": "pdf_forms_extract_fields",
  "args": {
    "pdfPath": "w2_template.pdf"
  }
}
Tip

Cache extracted field metadata (names + types) per template so subsequent fills are instantaneous.

Common failure mode

Some PDFs are scanned images (no AcroForm). In that case, combine OCR + an annotation strategy instead of form filling.

3) Fill values

Provide a map of field name → desired value. Prefer exact field names from step (2).

{
  "tool": "pdf_forms_fill",
  "args": {
    "pdfPath": "w2_template.pdf",
    "outputPath": "w2_filled.pdf",
    "values": {
      "EmployeeName": "Taylor Johnson",
      "SSN": "***-**-1234",
      "Wages": "82500"
    }
  }
}

When a field has a constrained set of options (checkboxes / radio groups), validate the input to avoid silent mis-fills.

4) Flatten the PDF

Flattening converts filled form fields into static page content so recipients can view but not edit.

{
  "tool": "pdf_forms_flatten",
  "args": {
    "pdfPath": "w2_filled.pdf",
    "outputPath": "w2_filled_flattened.pdf"
  }
}

5) Validate output

For production workflows, add validation checks:

  • Re-extract fields after fill and confirm expected values were applied.
  • Confirm the output opens in a strict PDF reader (some engines produce files that work only in permissive viewers).
  • Generate a thumbnail preview to show the user what they’re about to send.
