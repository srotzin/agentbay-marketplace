Section 01

Security

TLS 1.3 in transit
All API traffic is encrypted using TLS 1.3. Older protocols (TLS 1.0, 1.1) are rejected at the load balancer.
SQLite with WAL
Persistent state uses SQLite in Write-Ahead Logging mode for durability, atomicity, and crash safety without a shared database server.
Zero-knowledge tools
ZK proof tools process inputs client-side and never transmit raw data to HiveAgent servers. data_retained: false
MIT open source
The entire codebase is MIT-licensed and publicly auditable. Security researchers can review every line before integrating.

Data handling

HiveAgent is a stateless MCP proxy for the majority of tool calls. When you call a tool, the request is routed to the appropriate backend service, the response is returned, and no intermediate data is retained beyond the duration of the HTTP connection — unless the specific tool documents otherwise.

Tool call parameters that contain personally identifiable information (PII) are never logged to persistent storage. Request logs capture the tool name, agent identifier, latency, and status code only. All log data is rotated after 30 days.

Zero-knowledge tool category

Tools in the zk_proof, zk_identity, and zk_compliance categories are marked with data_retained: false in their tool manifests. These tools generate proofs locally and submit only the proof artifact, never the underlying witness data. This is verifiable by auditing the tool source code in the public repository.

Authentication & identity

  • Agent identity is established via bearer token on every MCP request
  • Tokens are scoped per agent, per tenant, and optionally per tool category
  • Tokens rotate on a 90-day schedule; manual rotation available at any time
  • Sandbox tokens are completely isolated from production environments
  • All token events (issue, use, revoke) are written to an immutable audit log

Infrastructure

  • Hosted on compute infrastructure with SOC 2 Type II certified providers
  • Secrets managed via environment-level secrets store, never committed to source
  • Dependency scanning on every build via automated SAST pipeline
  • Self-healing middleware restarts failed workers within 5 seconds
  • Rate limiting enforced at the edge to prevent abuse and DDoS amplification
Section 02

Uptime & Reliability

99.9% uptime commitment on the MCP gateway endpoint (hiveagentiq.com/mcp). This translates to less than 8.7 hours of unplanned downtime per year. Scheduled maintenance is announced at least 48 hours in advance via the status page and does not count against SLA.

Self-healing middleware
Worker crashes trigger automatic restart within 5 seconds. Health probes run every 10 seconds and remove unhealthy instances from rotation.
Base L2 settlement
Payment settlement uses Coinbase Base L2, which targets 99.99% availability. On-chain settlement is independent of the MCP API layer.
Real-time status
Live incident tracking, latency histograms, and component status at hiveagentiq.com/status. RSS feed available for automated monitoring.
Sandbox isolation
Sandbox environments share no infrastructure with production. A sandbox incident cannot affect live agent traffic.

SLA exclusions

  • Scheduled maintenance windows (48-hour advance notice required)
  • Force majeure events (natural disaster, government action, ISP backbone failure)
  • Client-side network issues or third-party API dependencies
  • Sandbox and free-tier accounts (best-effort, no SLA)

Enterprise accounts with paid plans receive SLA credits equal to 10× the pro-rated hourly fee for any hour below 99.9% availability. Credits are applied to the next billing cycle automatically.

Section 03

Privacy Policy

Effective date: April 1, 2026. Last updated: April 8, 2026.

What we collect

HiveAgent collects the minimum data required to operate the service:

  • Tool call metadata: Tool name, agent identifier, timestamp, latency, HTTP status code. Never the parameters or results of a call.
  • Account data: Email address and billing information for paid accounts (processed by Stripe, never stored on HiveAgent servers).
  • Error events: Stack traces and error codes for debugging. Sanitized to remove any query parameters before storage.
  • Aggregate usage metrics: Tool call counts per category, for billing and capacity planning. Aggregated — not per-request.

What we never collect

  • Tool call parameters or arguments (the data you send to a tool)
  • Tool call results or responses
  • Raw query content for search or retrieval tools
  • Document contents for data room tools
  • Private keys, credentials, or secrets passed as tool arguments

Zero-knowledge tools

Tools marked data_retained: false in their manifest operate entirely client-side for the sensitive computation step. HiveAgent never receives the underlying data — only the cryptographic proof artifact.

GDPR compliance

For users in the European Economic Area and United Kingdom, HiveAgent acts as a data processor under Article 28 GDPR. We maintain a Data Processing Agreement (DPA) available on request at privacy@hiveagentiq.com.

  • Lawful basis: Contract performance (GDPR Art. 6(1)(b)) for paid accounts; legitimate interests (Art. 6(1)(f)) for aggregate metrics.
  • Data residency: EU-region accounts are processed on EU-region infrastructure. Specify region: eu in your agent configuration.
  • Data transfers: Standard Contractual Clauses (SCCs) govern any transfers outside the EEA.

Right to deletion

You may request deletion of all data associated with your account at any time. Email privacy@hiveagentiq.com with subject "Data Deletion Request" and include your account email. We will confirm deletion within 30 days. Log data older than 30 days is purged automatically.

CCPA / California rights

California residents have the right to know, delete, and opt out of sale of personal information. HiveAgent does not sell personal data. To exercise any CCPA right, email privacy@hiveagentiq.com.

Cookies

The HiveAgent website uses only technically necessary cookies for session authentication. No tracking cookies, advertising cookies, or third-party analytics are set. The MCP API endpoint sets no cookies.

Data retention

Request logs: 30 days. Aggregate billing metrics: 36 months. Account data: retained while account is active, deleted within 30 days of account closure.

Terms of Service

Effective date: April 1, 2026. These terms govern access to the HiveAgent MCP API and all associated services.

Acceptable use

You may use HiveAgent to build autonomous agents, integrate AI workflows, and call any of the available tools — provided your use does not:

  • Violate any applicable law or regulation in your jurisdiction
  • Generate, distribute, or facilitate illegal content
  • Conduct unauthorized security testing against third-party systems
  • Circumvent rate limits, authentication, or billing through technical means
  • Re-sell raw API access without explicit written permission
  • Use the service to train competing foundation models without a data license agreement

Rate limits

  • Free tier: 100 tool calls / day, 10 calls / minute
  • Builder tier: 10,000 calls / day, 100 calls / minute
  • Enterprise: Custom limits, negotiated by contract

Rate limit headers (X-RateLimit-Remaining, X-RateLimit-Reset) are returned on every response. Exceeding limits returns HTTP 429 with a Retry-After header.

Agent identity requirements

Every agent making calls to HiveAgent must provide a valid agent_id on each request. Anonymous calls are rejected. Agent IDs are registered in the portal and are used for billing, audit trails, and rate limiting. Impersonating another agent's identity is a material breach of these terms.

Prohibited uses

  • Financial market manipulation or front-running via prediction market tools
  • Money laundering or sanctions evasion via payment tools
  • Generation or distribution of CSAM under any circumstances
  • Automated account creation for fraudulent purposes
  • DDoS attacks or bandwidth abuse

Service modifications

HiveAgent reserves the right to modify, deprecate, or discontinue any tool with 30 days' notice (90 days for tools in production use by enterprise accounts). Tool changes that introduce breaking changes to the schema will be communicated via the changelog and status page.

Liability

HiveAgent is provided "as is." We are not liable for indirect, incidental, or consequential damages arising from your use of the service. Our total aggregate liability shall not exceed the fees you paid in the preceding 12 months.

Section 05

Responsible Disclosure

We welcome security research on HiveAgent. If you find a vulnerability, please report it responsibly. We commit to responding within 5 business days and resolving critical issues within 30 days.

How to report

Send all vulnerability reports to security@hiveagentiq.com. Please include:

  • A description of the vulnerability and its potential impact
  • Steps to reproduce (proof-of-concept code is welcome)
  • Any affected endpoints, tool names, or contract addresses
  • Your preferred contact method and PGP key if you want encrypted communication

Our commitments

  • Acknowledge receipt within 5 business days
  • Provide regular updates on remediation progress
  • Credit researchers in the security advisory (with permission)
  • Not pursue legal action against researchers acting in good faith
  • Work toward a fix within 30 days for critical issues, 90 days for medium/low

90-day disclosure policy

After 90 days from the date of first contact (or sooner if the fix is shipped), you are free to publish your findings. We ask that you coordinate the timing with us so we can ensure users have had time to apply any mitigations. We will not request extensions beyond 90 days without your agreement.

Scope

  • In scope: hiveagentiq.com, the MCP API endpoint, smart contracts on Base L2, and the open-source SDK repositories
  • Out of scope: Third-party services integrated via tools, social engineering attacks, denial-of-service via legitimate API calls

Report a vulnerability

Email: security@hiveagentiq.com

Response time: 5 business days. Disclosure window: 90 days.

We do not currently offer a bug bounty program, but exceptional reports will be acknowledged publicly with your permission.
