How to use AgentBay MCP tools: a practical guide

This page shows a repeatable workflow for discovering tools, calling tools via JSON-RPC, and composing multi-step tool-first automations against an MCP server.

1) Discover what tools exist

Start with tools/list. It returns tool names and JSON schemas you can use to build calls.

curl -s -X POST https://www.hiveagentiq.com/mcp \
  -H "Content-Type: application/json" \
  -H "User-Agent: AgentBay-Tutorial/1.0" \
  -d '{
    "jsonrpc":"2.0",
    "id": 1,
    "method": "tools/list",
    "params": {}
  }'

2) Call a tool (the MCP way)

MCP tool calls use tools/call with a name and a structured arguments object. Treat the tool schema like an API contract. 

curl -s -X POST https://www.hiveagentiq.com/mcp \
  -H "Content-Type: application/json" \
  -H "User-Agent: AgentBay-Tutorial/1.0" \
  -d '{
    "jsonrpc":"2.0",
    "id": 2,
    "method": "tools/call",
    "params": {
      "name": "example__tool_name",
      "arguments": {
        "input": "hello"
      }
    }
  }'

If a call fails, read the error payload and adjust the arguments to match the schema. Most integration mistakes are "shape" mistakes.

3) Compose a tool-first workflow

Many useful agents follow a simple pattern:

  • Plan: decide which tools and parameters you need.
  • Fetch: call tools to gather facts and state.
  • Transform: compute derived fields (scores, rankings, diffs).
  • Act: call tools that write, send, book, or update.
  • Verify: re-fetch to confirm the action took effect.

Example: "find then act" flow

// pseudo-code
const tools = await toolsList();
const candidates = await toolsCall("search__something", { query: "..." });
const best = rank(candidates);
await toolsCall("create__something", { ...best });
const confirmation = await toolsCall("get__something", { id: confirmationId });

Tool calling checklist

  • Use tools/list first to get tool names and schemas.
  • Validate input types (string vs number, arrays vs objects).
  • Prefer deterministic fields (IDs, ISO timestamps) over free-text.
  • Log responses during development.
  • Retry safely only for idempotent calls.

Common pitfalls

  • Using the wrong tool name prefix.
  • Missing required fields from the schema.
  • Sending a number as a string (or vice versa).
  • Not handling paginated results.

Next steps

Note: This guide is intentionally tool-agnostic. Use the tool schemas returned by tools/list to discover real tool names and required arguments.
