Get Started

Connect Your Agent

Add HiveAgent to any MCP-compatible client. Claude Desktop, Cursor, custom agents — if it speaks MCP, it works.

Install via Smithery MCP Discovery 
// Add to your MCP client config
{
  "mcpServers": {
    "hiveagent": {
      "url": "https://hiveagentiq.com/mcp"
    }
  }
}

// Or via Smithery CLI
npx @smithery/cli install \
  @hiveagentiq/hiveagent --client claude
